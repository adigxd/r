# Fonts

`JetBrainsMonoNL-Regular.ttf` is JetBrains Mono (NL, regular), the font of the chat (`CHAT_FONT` in `.env.pre`).

JetBrains Mono is made by the JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) and is free to use and share under the SIL Open Font License 1.1 (https://openfontlicense.org). The font file here may be used, copied and passed on as long as this notice goes with it.
