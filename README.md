# r

### What?

The best voxel engine ever ...

### CLI:

```
pip install -r req.txt
cp .env.pre .env
python main.py
```

### Customization:

- Create your own map in `DIR-Maps` ... set your map in `.env` (`_MAP`)
- Edit other variables in `.env`
- Edit the textures in `DIR-Resources/IMG-Texture.png`
